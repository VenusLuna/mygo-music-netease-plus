# 网易云音乐 Plus · MyGo Music 插件

在 [MyGo Music](https://github.com/egoist/mygo-music) 里搜索、浏览和播放网易云音乐。插件 ID 为 `netease-plus`，要求 MyGo Music **0.1.20 或更新版本**，不需要自建服务、不需要安装依赖。

> 本项目基于 [sogud/mygo-music-netease](https://github.com/sogud/mygo-music-netease)（v0.1.7，提交 `2b7f726`）修改而来，继续以 AGPL-3.0 发布，原作者和贡献者的提交历史已保留。它不是官方版本，也不是原项目的替代品，而是一个侧重播放稳定性和大歌单的分支。

本项目与网易云音乐、MyGo Music 均无隶属关系。可播放的内容、音质和账号权限由网易云音乐决定，相关服务可能随时调整，插件会尽力给出明确的错误说明。请在使用时遵守网易云音乐的用户协议。

当前版本 **0.2.6**，各版本改动见 [更新日志](CHANGELOG.md)，安装包见 [Releases](https://github.com/VenusLuna/mygo-music-netease-plus/releases)。

## 功能

### 搜索

- 搜索歌曲、专辑、歌手、歌单和播客，每页 30 条，支持继续翻页。
- 在搜索框输入时给出关键词联想，最多 10 条，自动去重。
- 搜索和联想都可以在未登录时使用，部分结果在未登录时可能受限。

### 发现与浏览

- **发现音乐**：每日推荐、私人雷达、个性化歌单、推荐歌单，以及「私人漫游 / 熟悉的歌 / 新发现」电台。
- **排行榜**：网易云音乐榜单列表。
- 推荐歌单加载失败时，首页该区域显示重试入口，其他入口不受影响。
- 每日推荐、私人雷达和个性化歌单需要登录。

### 账号与登录

- 用网易云音乐手机 App 扫码登录，登录过程在 MyGo Music 内完成。
- 登录状态保存在插件的本地存储中，重启 MyGo Music 后自动恢复，不需要重复扫码。
- 登录失效时插件会清理本地状态并提示重新登录，不会把失效状态当成游客继续使用。

### 歌单与喜欢

- 读取账号的全部歌单，以及任意公开歌单的详情。
- 歌单一次载入全部曲目，上限为 10000 首；超过 20 秒会停止并说明已载入数量，避免长时间等待。
- **喜欢 / 取消喜欢**歌曲；喜欢列表的顺序与网易云音乐「我喜欢的音乐」一致。
- **完整歌单管理**（需要登录）：
  - 创建、重命名、删除歌单；
  - 收藏 / 取消收藏别人的歌单；
  - 添加、移除歌曲；
  - 调整歌曲顺序，按完整顺序提交，不通过删除再添加模拟；
  - 已存在的歌曲不会重复加入，混合批次只补充缺失的歌曲。

### 歌手与专辑

- 歌手页：热门歌曲、全部专辑、关注 / 取消关注。
- 专辑页：曲目列表、收藏 / 取消收藏，并显示当前收藏状态。
- **我的收藏**：分页浏览账号已收藏的专辑，每页 50 张。
- 关注与收藏需要登录；未登录点击会提示先扫码登录。

### 播客

- **我的播客**：读取账号已订阅的播客，支持分页。
- 播客页：节目列表分页、单集播放。
- 节目评论支持分页、发表、点赞和取消点赞。

### 播放与音质

- 支持三档音质：`standard`、`high`、`lossless`；无损使用 FLAC，其余使用 MP3。
- 播放线路自动选择，被拒绝或未给出完整音频时自动重试，尽量减少中断。
- 只接受 HTTPS 且属于网易云音乐音频域名的地址，其他地址按不可播放处理。
- 只播放账号有权限的完整音源；无法完整播放时说明原因，不会把片段当作完整歌曲。

### 歌词

- 返回 LRC 歌词和翻译，由 MyGo Music 的播放界面显示。
- 一条线路没有歌词时会尝试另一条，不把空结果当成纯音乐。
- 播客节目没有歌词。

### 评论

- 歌曲和播客节目的评论列表，支持分页。
- 发表评论（最多 140 字）、点赞 / 取消点赞（需要登录）。
- 暂不支持回复评论。

### 我的云盘

- 列出网易云音乐云盘里上传的歌曲，最多 500 首。
- 按文件本身的码率播放，不套用音质档位。

### 暂未提供

以下能力目前不在插件内，界面不会出现对应入口：

- 心动模式（HEART）；
- 修改播客订阅；
- 回复评论；
- 歌单滚动加载与逐字歌词。

## 和原版的区别

| | [原版 sogud/mygo-music-netease](https://github.com/sogud/mygo-music-netease) | 本项目（Plus） |
|---|---|---|
| 插件 ID / 名称 | `netease` / 网易云音乐 | `netease-plus` / 网易云音乐 Plus，可与原版同时安装，互不覆盖 |
| 播放线路 | 单一线路，失败后只重试一次 | 多线路自动重试，尽量完成播放 |
| 歌单歌曲上限 | 前 1000 首 | 完整读取，网易云音乐上限 10000 首，实测 9862 首歌单约 8 秒载入 |
| 歌曲详情加载 | 400 首一批，整批并发 | 200 首一批、最多 8 路并发，5 分钟缓存，再次打开歌单约 0.8 秒 |
| 超大歌单 | 无保护 | 20 秒预算，超时说明已载入数量 |
| 功能 | 搜索、推荐、扫码登录、歌词、评论（只读）、播客、歌单编辑等 | 另增我的云盘、发表评论与评论点赞、搜索联想、关注歌手、收藏专辑与「我的收藏」 |

注意：插件 ID 不同，首次使用需要重新扫码登录，原版的登录状态不会带过来。歌单一次载入全部曲目，暂不支持滚动加载。

## 安装

三种方式任选其一：

1. **从 GitHub 安装**：MyGo Music → 设置 → 插件 → `+` → 从 GitHub 安装，填入 `VenusLuna/mygo-music-netease-plus`。
2. **从 Release 安装**：在 [Releases](https://github.com/VenusLuna/mygo-music-netease-plus/releases) 下载 `netease-plus-<版本>.zip`，从本地安装。
3. **从文件夹安装**：选择本项目目录。

安装后在来源选择器中选择 **网易云音乐 Plus**。插件与 `netease`（原版）可以同时安装，两者登录状态互不影响。

## 使用

1. 点击 **登录**，用网易云音乐手机 App 扫码并确认；登录成功后侧栏出现「我喜欢的音乐」「我的收藏」「我的播客」。
2. 在搜索框输入歌名、歌手或专辑，选择搜索类型并翻页；输入过程中会出现关键词联想。
3. 打开歌手或专辑页，使用页面上的关注 / 收藏按钮；已收藏专辑集中在侧栏「我的收藏」。
4. 在歌单页创建、重命名、删除歌单，收藏别人的歌单，或添加、移除、排序歌曲。
5. 首页「发现音乐」集中了每日推荐、私人雷达和个性化歌单；「私人漫游」是独立专页，可持续下一首。
6. 卸载或登出会清除本地登录状态；再次使用需要重新扫码。

## 数量与限制

| 项目 | 上限或行为 |
|---|---|
| 歌单歌曲 | 上限 10000 首；载入时间预算 20 秒，超时说明已载入数量 |
| 歌曲详情批量 | 每批 200 首，最多 8 路并发 |
| 详情缓存 | 5 分钟、最多 20000 条，仅内存 |
| 搜索 | 每页 30 条 |
| 搜索联想 | 最多 10 条，去重 |
| 云盘 | 最多 500 首 |
| 已收藏专辑 | 每页 50 张 |
| 评论 | 每页 30 条；单条最多 140 字 |
| 喜欢列表 | 每页 30 首 |
| 播客节目 | 每页 30 集 |
| 歌单数量 | 超过 2000 个时会提示无法完整加载，避免无限翻页 |

## 隐私与数据

- 插件只在本地保存两类数据，均写入插件的本地存储：
  - `session`：登录凭证和账号昵称、头像；
  - `deviceId`：随机生成的安装标识，用于请求参数，不包含账号信息。
- 网络请求只发往 `plugin.json` 中声明的网易云音乐域名，不经过任何第三方服务器。
- 错误信息只包含状态和提示文案，不包含响应体、请求头或登录 Cookie。
- 所有写操作（喜欢、歌单编辑、关注、收藏、评论）都需要登录；登出会清空登录状态与缓存。

## 故障排查

### 私人漫游、熟悉的歌或新发现没有歌曲

这些电台依赖网易云音乐的个性化服务。关闭该服务时，即使已经登录，也可能返回空列表。

请在网易云音乐官方 App 的 **设置 → 消息和隐私 → 个性化服务** 中确认开关已开启，然后回到 MyGo Music 点击 **开始收听**。电台卡片会显示这项前置条件；确认已关闭时，插件会返回带恢复说明的错误。若已开启仍为空，请稍后重试。

### 提示需要重新登录

登录状态已过期。插件会清理本地状态，请重新扫码登录。

### 无法完整播放

账号没有该歌曲的完整播放权限，或歌曲在当前地区不可用。VIP、数字专辑和地区限制由网易云音乐决定。可以先在官方客户端确认该歌曲能否正常播放，再回到插件重试。

### 请求被拒绝或页面提示服务暂不可用

服务端可能临时限制了请求，或接口发生调整。稍后重试；若持续出现，请查看项目 [Issues](https://github.com/VenusLuna/mygo-music-netease-plus/issues) 是否有相同情况。

### 云盘歌曲的码率与所选音质不同

云盘按上传文件本身播放，不进行转码，也不套用音质档位。

### 收藏或关注按钮点击后没有变化

确认已经登录并完成扫码确认。仍失败时，界面会显示失败原因。

## 开发

运行不需要构建或依赖安装；Node 和 Python 只用于本地检查与打包：

```sh
npm run check   # 语法检查
npm test        # 45 项测试，使用模拟的接口响应
npm run pack    # 生成 dist/netease-plus-<版本>.zip
```

项目结构：

| 文件 | 用途 |
|---|---|
| `index.js` | 插件全部实现，单文件 ES module，无第三方依赖 |
| `index.test.mjs` | `node:test` 测试，模拟 `fetch` 与运行环境 |
| `plugin.json` | 插件清单：版本、网络域名、侧栏入口 |
| `pack.py` | 打包 `plugin.json`、`index.js`、`LICENSE`、`THIRD_PARTY_NOTICES.md`、`README.md` |
| `CHANGELOG.md` | 每个版本的改动与验证记录 |

实现约定：

- 插件运行在 MyGo Music 提供的环境中，只使用该环境给出的网络与存储能力，不引入第三方依赖。
- 存储只在动作执行期间访问，不在模块加载阶段访问。
- 所有请求带超时；可能耗时较长的读取要设置时间预算，并说明已获取的部分。
- 新增能力时保持动作名为小写驼峰、参数与返回值为纯 JSON，便于 MyGo Music 直接展示。

发布流程：

1. 更新 `plugin.json` 与 `package.json` 的版本号，并在 `CHANGELOG.md` 记录新增、验证和升级说明。
2. 执行 `npm run check`、`npm test`、`npm run pack`。
3. 提交后打标签 `v<版本>`，推送到 `plus` 远程的 `main` 与标签。
4. 用 `gh release create v<版本> dist/netease-plus-<版本>.zip` 创建 Release。

自动化测试只覆盖模拟响应；真实账号的写操作（登录、歌单编辑、关注、收藏、发表评论）仍需在 MyGo Music 中人工验收。
